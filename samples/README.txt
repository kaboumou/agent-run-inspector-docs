Agent Run Inspector — free demo pack
====================================

These are SYNTHETIC example sessions (no real user, customer, or company
data) plus the reports Agent Run Inspector generates for them.

What to look at:

  reports/example-retry-loop-report.html
      The flagship case: the same failing command repeated 4 times,
      a recovered dependency sync, and a run that finished with
      unresolved items.

  reports/example-normal-report.html
      A clean run: tools completed, no findings.

  reports/example-provider-error-report.html
      A run interrupted by a provider error mid-task.

  reports/example-interrupted-report.html
      A run exported mid-step: unknown completion state, unfinished call.

  example-*.json
      The raw inputs (same shape as `opencode export [sessionID]` output).

Open any report in a browser. Everything is local; the reports are static
files with no scripts and no network calls.

The full product (same engine, any export, HTML + JSON output) is a one-time
purchase from the store page.
